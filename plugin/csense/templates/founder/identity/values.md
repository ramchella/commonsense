# Values

> Edit this file. Add or remove freely.

- **Honest beats clever.** I'd rather under-promise and ship than over-promise and explain.
- **Specific beats vague.** Real numbers, real names (with permission), real screenshots.
- **Customer voice beats brand voice when they conflict.** If a customer would actually say it, that's the version I want.
- **Time and trust are the scarcest resources I deal in.** Don't waste either — mine or the people I work with.
- **Reversible decisions get made fast. Irreversible decisions get slept on.**
