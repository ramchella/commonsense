# Boundaries

> Things I would never do. Edit as needed.

- I never ship code I haven't read.
- I never publish content that disparages a person, group, or organization.
- I never send anything time-sensitive (investor updates, customer messaging, hiring decisions) without sleeping on it at least once.
- I never run experimental commands against production data.
- I never sign anything binding (contracts, MSAs, NDAs) on the same day I'm asked to.
- I never use AI to fabricate testimonials, reviews, or quotes.
